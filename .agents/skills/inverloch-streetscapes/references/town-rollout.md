# Extending photo-based reconstruction across Inverloch

Treat the current whole-town model as the fallback for every street. Its town file contains 881 road records, 311 mapped building records and 5,712 generated houses across a model extent of about 8.0 × 6.9 km. A named street may span several road records. Recheck the counts when sizing a later rollout. [Town data at the planning baseline](https://github.com/Ashley-Pettit/3dModels/blob/c2b4b39/town3d/town.json)

## Pilot one connected walk

Use the [hotel-to-Glade fieldwork map, two-sided inventory and town geometry exporter](../../../../tools/streetscapes/README.md) to pick up the pilot at its surveyed boundaries. It identifies the Ramsey crossing and car-park transition that still need a dated local photo walk.

Start at the Esplanade Hotel, continue through the A’Beckett–Williams Street junction onto Ramsey Boulevard, and end at an identifiable foreshore entrance selected from the available evidence. In one walk the viewer passes a detailed frontage, turns a junction and emerges into open space. Use the A’Beckett camera route as the town-centre comparison and the Norman Road example as a residential comparison. Before carrying model data forward from the A’Beckett trial, check the source of each feature. Re-author any Street View-derived features from independently reusable evidence. [A’Beckett streetscape](https://github.com/Ashley-Pettit/3dModels/pull/221) · [Norman Road exterior](https://github.com/Ashley-Pettit/3dModels/pull/218)

| Stage | Deliverable | How to decide what comes next |
| --- | --- | --- |
| Inventory | Give each junction-to-junction stretch a stable ID with two street sides. Against each side, record coverage, date, permitted uses, missing views and any native footprint that spans several businesses. Assign shared corners one owner. | Pick stretches with connected coverage. Request a short local photo walk for gaps that would change the visible scene. |
| Build the pilot | Author repeated objects as a small set of frontage and streetside types. Store only the per-location facts that vary, such as wall endpoints, setback, bay widths, roof type, awning depth, parking direction, tree spacing and source ID. Leave unsurveyed properties on the existing fallback. | Walk in both directions and turn the junction. A reviewer should be able to follow the route, recognise the entrance and identify where a building or feature is still approximate. |
| Measure the pilot | Record authoring hours, length covered on each street side, proportion backed by dated reusable imagery, and visual corrections after review. Measure cold entry, the busiest walking view and a return trip to a previously visited stretch. | Estimate the next area from hours per verified frontage or street-side kilometre, split by commercial, residential and foreshore work. Price new photography separately. |
| Expand by adjoining routes | Extend the retail and civic core first. Cover the foreshore entrances and paths, then residential routes around Norman Road and Surf Parade. Keep ordinary homes procedural where frontage evidence is thin. Reserve individual models for landmarks and particularly recognisable or requested properties. | Prioritise adjoining missing stretches, important viewpoints and dated changes. Track verified street-side length separately from streets that have only generated coverage. |

For imagery intake, a local contributor can capture both directions at each junction and one unobstructed view of each distinct frontage from the public street, noting capture date and permission to model it. An older licensed photograph can establish a lasting roofline while a recent contributor photo establishes the tenant and kerb layout. The lifegames collection licenses its own photographs under CC BY 2.5 Australia. Check item identity and date before using one. Victoria’s aerial and building products have different coverage and access conditions. Keep the project’s existing OSM attribution and observe applicable ODbL obligations when publishing derived map data. ## Keep an entire town affordable

Start the pilot with the existing renderer. When a second corridor repeats enough work to justify it, extract a shared catalogue and a small street-side data format. A corner shop can own one footprint and two connected faces. A row of shops can share one shell, awning material and collision outline. Keep source links, rights and confidence in authoring data, and export what the viewer needs along with required credits.

If further streets would materially enlarge the common app download or stall movement, package optional frontage detail by neighbourhood. Use the town’s coarse geometry at distance. Fetch and construct nearby facades in bounded batches, share materials across packages and release distant detail. Give a junction a stable owner so adjoining packages can meet in either load order. Profile arrival, turning back, low-detail devices and repeated visits before adopting that design. These packages cover buildings and street furniture.

The A’Beckett trial added **10,484 compressed bytes** to the cold same-origin download and kept the request count at **10**. Median draws fell from **347 to 326**, while median GPU time rose from **1.44 to 1.92 ms**. Both builds delivered a median **16.7 ms** frame on the test laptop. One route establishes a comparison point. Set a town-wide budget only after measuring representative commercial, residential and foreshore routes on desktop and the target phone. [Measured route, device and data](https://github.com/Bangerz/3dModels/blob/baa813f2c4c54b503491fcc611016fc44df86fd1/abeckett-street/route-metrics.json)

Keep the renderer or loader change in its own PR when it becomes necessary. Deliver subsequent PRs as independently reviewable, adjoining stretches, each with source dates, a matched view across its boundary, a measured cost and the remaining uncertainties. Revisit features when newer evidence changes them. Tenant signs and crossings usually need checking sooner than building footprints.
